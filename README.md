# obscure-kernel
Obscure Kernel GUI v11.0 — это ультимативный голосовой ИИ-помощник и графическая панель управления, созданная специально для операционной системы Arch Linux под управлением тайлового оконного менеджера Hyprland. Проект объединяет в себе локальную нейросеть для интеллектуальной обработки команд, продвинутый синтез речи для общения и интерфейс на базе PyQt6 для гибкой настройки всех параметров системы в реальном времени. Для начала работы необходимо подготовить операционную систему и установить базовые пакеты через официальные репозитории Arch Linux. Откройте терминал и выполните команду sudo pacman -S python-pyqt6 python-pyaudio python-requests python-feedparser sox xdotool playerctl. Эти пакеты обеспечат корректную работу графического интерфейса, захват и наложение эффектов на звук, парсинг данных из сети, а также симуляцию нажатий клавиш и управление системным мультимедиа. Сразу после этого установите необходимые модули Python, выполнив команду pip install --user SpeechRecognition pynput ollama --break-system-packages, которая загрузит библиотеки для распознавания речи, создания игровых макросов и взаимодействия с локальным искусственным интеллектом.  
​Ядро использует локальную языковую модель для парсинга нелинейных команд терминала и генерации ответов. Сначала установите сам сервер нейросети командой sudo pacman -S ollama. Чтобы служба запускалась автоматически и работала в фоне, активируйте ее командой sudo systemctl enable --now ollama. По умолчанию скрипт настроен на использование легковесной модели phi3. Для ее загрузки и инициализации введите в терминале ollama run phi3. Дождитесь окончания скачивания весов модели, после чего терминал можно закрыть — нейросеть продолжит стабильную работу в фоновом режиме. Для генерации голосовых ответов ассистента используется локальный офлайн-движок Piper. Вам потребуется самостоятельно скачать бинарный файл Piper и русскую языковую модель с расширением onnx. Обязательное условие: поместите скачанные файлы движка и голоса в одну папку рядом с самим скриптом, а затем при первом запуске программы зайдите во вкладку CONFIG и укажите к ним точные пути.  
​Когда вся среда подготовлена, запустите главный исполняемый файл проекта командой python3 obscure_app.py. На экране развернется панель управления, а микрофон перейдет в режим фонового прослушивания. Чтобы дать системе доступ к диалогу и активировать ядро, произнесите вслух одно из слов-триггеров: ядро, кернел, обскур или obscure. Услышав триггер, ассистент сообщит о готовности принимать директивы. Чтобы узнать все доступные возможности, просто скажите слово помощь, и полная справка со всеми системными макросами моментально выведется в терминал интерфейса. Для автоматической генерации команд Arch Linux используйте кодовое слово терминал и назовите нужное действие, а чтобы вернуть систему в энергосберегающий режим ожидания, скажите отбой или усни.
