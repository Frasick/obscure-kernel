# obscure-kernel
Obscure Kernel GUI v11.0 — ультимативный голосовой ИИ-помощник и GUI-панель для Arch Linux (Hyprland). Интегрирует локальную нейросеть Ollama для генерации команд, офлайн-синтез Piper и интерфейс PyQt6. Управляйте системой, макросами и терминалом с помощью голоса. Активация: «ядро» или «obscure». Запуск: python3 obscure_app.py
